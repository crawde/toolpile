About JSON and YAML

JSON (JavaScript Object Notation) uses braces and brackets with strict syntax. YAML (YAML Ain't Markup Language) uses indentation, making it more human-readable. YAML is commonly used for configuration files (Docker, Kubernetes, CI/CD), while JSON is standard for APIs and data exchange.
