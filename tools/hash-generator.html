Frequently Asked Questions

What is a cryptographic hash?

A cryptographic hash function takes an input (message) and returns a fixed-size string of bytes. The output (digest) is unique to each unique input — even changing one character completely changes the hash. This property makes hashes useful for verifying data integrity, storing passwords, and digital signatures.

Which algorithm should I use?

SHA-256 is the gold standard for most use cases — it's fast, secure, and widely supported. MD5 produces a 128-bit hash and is fast but cryptographically broken — use only for checksums. SHA-1 (160-bit) is deprecated for security. SHA-512 (512-bit) offers the highest security margin and is faster than SHA-256 on 64-bit systems.

Can I reverse a hash to get the original text?

No. Hash functions are one-way by design. There is no mathematical way to reverse a hash. Attackers use precomputed tables (rainbow tables) or brute force, which is why long, random inputs are more secure.

Is my data safe?

All hashing is done in your browser using the Web Crypto API (SHA family) and a JavaScript implementation (MD5). Nothing is sent to any server.
