What is Base64?

Base64 is a binary-to-text encoding scheme that converts binary data into a printable ASCII string. It's commonly used in email attachments, data URIs, API tokens, and transmitting binary data over text-only protocols. Each Base64 character represents 6 bits of data, making the encoded output ~33% larger than the original.
